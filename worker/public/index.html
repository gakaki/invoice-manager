功能

  • 三种录入方式：直接输入 / 粘贴文字（启发式解析字段）、选择图片、Android 系统选择器自带相机拍摄。
  • 云端 OCR：Cloudflare Worker 调用 Workers AI 视觉模型，自动抽取发票代码、号码、开票日期、购销双方及税号、金额、税额、价税合计。
  • 发票管理：列表、新增、编辑、删除，数据持久化在 Cloudflare D1（已按行读取额度优化查询）。
  • 多选拼接输出：勾选多张发票，按约定格式拼接为文本，一键复制到剪贴板。
  • 技术栈：Rust + Native Shell（nsh.dev）原生跨平台 UI，blaze 增量编译；后端 Cloudflare Worker + D1 + Workers AI。
